# Port 1.0.0.3460 -> 1.0.0.3479 (2026-11-01)

Steam updated the game on 2026-11-01 15:09 to 1.0.0.3479 (game version 2.04.05, PE 0x6AE6E3E8,
SizeOfImage 0x14073000, 330,738,072 bytes). The mod's version check switched it off as designed
("Co-op+ is off ... the game runs normally"). A copy of this exe is now kept in build/exe-archive (git-ignored)
so the next port can diff two builds.

## How each value was found (build/port3479)
- Code with a recorded head (`heads.py`, `near.py`): the head searched in the new image, the hit nearest the old
  address taken; CC update and the movement step double-checked as vtable slots (`vt.py`).
- Vtables (`vt.py`): RTTI class name -> type descriptor -> locator -> vtable. All +0x1000.
- Data globals (`globals.py`): the upstream signatures (one match each), RIP-relative target decoded.
- Clock flag: the `cmp byte [rip+d],0` targets in that region; 0x70D2D75 has 15 sites and live reads flag 1,
  +0x3C advancing.
- Troc table (`troc.py`, live, title screen): 1175 handlers at 0x6E87D10..0x6EBB370, same span as 3460;
  every opcode identical to 3460 (`troc_3479.txt`).

## Also found on the way (3460, kept for 3479)
- Upstream's "OtherEquipItemAck writer" site is, on 3460/3479, one of 41 identical log formatters (their format
  strings are the game's Korean error messages). Replaced by the equipment watcher (offsets_3460.h).
- Startup crash about one launch in five, inside sl.dlss_g.dll / sl.interposer.dll / d3d11.dll: NVIDIA Streamline
  reacts to ANY throwaway swap chain (D3D12 or D3D11). The overlay now reads Streamline's proxy swap chain class
  (`sl::interposer::DXGISwapChain`) from RTTI; 6/6 clean launches after, plus every launch since.

## Menus (Co-op+, 3479)
- Name tags were drawn over the world map. Snapshots of exe+0x70C0000..0x7240000 with the map, inventory, journal,
  skills and pause menu open vs closed: six bytes flip every time. The game's input-mode push (exe+0xF20AC7)
  saves `kGameplayInput` (0x71982B8) on a stack and clears it; the pop restores it, so nested menus keep it 0.
  game/ui_state.cpp checks the push's `movzx eax,byte [rip+d]` resolves to it, then hud.cpp skips world markers
  while it is 0. Live: no tag on the map, tag back on closing.
