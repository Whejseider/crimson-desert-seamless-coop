## Live quests
- Quests advance only in each game's in-process server. Mirroring the client's own requests works for go-to steps
  (MissionTriggerInOutReq with our user key). The quest cheat is compiled out on retail.
- General route (all step kinds): call the advancement routine with the mission's index, inside a request the server
  is handling. It runs the step's consequences (next step, rewards, quest gauge, a cleared camp's spawns removed).
  It also starts and finishes a step that was never started, so the receiver only advances steps under way.
- Found by a memory diff (101 copies of a mission key, 3 changed 2 -> 5) and a hardware watch on those bytes.

## Slow motion (Focus)
- Not a world-speed number: float and double scans found none. The game's names (ClientFrameEventTimeScale,
  TimeScalePreset with _globalTimeScale / _playerTimeScale) exist, but that frame event's handler never ran for Focus.
- Focus is a server "special mode": EnableSpecialModeAck mode 101 at the start, DisableSpecialModeAck at the end; the
  client never asks for it. Dropping the Enable keeps Focus (animation, Spirit refill: stat 0x17 15915 -> 30000 in 5 s)
  without the slow motion or the tint.

## Test kit (build/port3460, build/port3527; not in git)
- Game input without the user: keybd_event with the key's scan code (presskey.ps1, focuskey.ps1). focusprobe.ps1
  -KeepS retries Focus until it shows; tintwatch.ps1 spots the Focus tint on the game window (any monitor). The most
  reliable signal is the server message (3126 / 2701), not the screen.
- dev script: fscan / ffilter / fwatch, dscan / dfilter / dwatch, memscan / memdiff / memwatch, advance, waitfile.
- Saves: tests run in a scratch co-op world (Steam Cloud uploads save slots when the game exits); savecheck.sh
  compares only the save slots; a stopped background test can leave its inner script alive, so each script closes
  only the game process it started.
- Simulator: cdmp_peer --far START,END,M (partner far away and back), --record / --mode replay.

## Co-op behaviour findings
- A partner far away (another region) cannot be drawn on ground the game has not loaded; their character is now
  hidden beyond 600 m and loaded again within 400 m. No distance limit otherwise.
- A friend's Focus does not slow your world (replay test); your Focus with the friend's copy nearby was stable.
