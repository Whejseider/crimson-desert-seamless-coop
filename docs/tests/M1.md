# M1 Ghosts: two-PC checklist (Steam join, invites, presence)

Needs: two PCs, two Steam accounts that are friends and both own the game, both on 1.0.0.3446, both installed
from the SAME package zip (the build id must match). Denuvo allows 5 PC activations a day. Back up saves (the
installer does). Nobody saves while the other player is in their world.

Roles: A = host (the user), B = friend.

## 1. Invite flow (both games running)
- [ ] A and B load their own saves. Both panels (F8) show their own room code and `Ctrl+F1: invite`.
- [ ] A presses Ctrl+F1, the Steam overlay opens, A invites B.
- [ ] B accepts in the Steam chat/overlay. B's log: `Join: Steam asked to join lobby ...`,
      `Network stopped (joining another world)`, `Co-op+: now joining a friend's world`,
      `Room: code ... -> host SteamID64 <A>`, then `Steam: session with <A> is connected`.
- [ ] A's log: `Network: player at steam:<B> is joining`, then connected. Panels say `connected to '<name>'`
      with the Steam names on both sides.
- [ ] B appears in A's world and A in B's (moves, animations, gear). Minimap arrow and map pin.
- [ ] Steam friends list: A shows "Co-op+: hosting (2/2)", B shows "Co-op+: in <A>'s world"; grouped together.

## 2. Join Game, game not running
- [ ] B quits to desktop. In Steam, B right-clicks A > "Join Game".
- [ ] Steam starts B's game; B's log: `Join: Steam started the game to join lobby ...`; after B loads a save,
      B connects to A without typing anything.

## 3. Join Game, game running
- [ ] Both in game, B not connected (B pressed Ctrl+F2). B uses "Join Game" on A from the Steam overlay friends list.
- [ ] B switches to guest and connects (same log lines as 1).

## 4. Leave and come back
- [ ] B presses Ctrl+F2: B's log `Network stopped (left the other player's world)`, `now hosting our own world`.
      A's log: `<B> left; waiting for a player`. B's own enemies come back (zone restore), no copies left over.
- [ ] B joins again (invite or Join Game) and reconnects.

## 4b. Invite-only (`[net] join=invite` on A)
- [ ] A's log: `Config: who can join: invited friends only`. B's Steam list shows A without "Join Game".
- [ ] B tries the room code or an old "Join Game": A's log `... is not in our lobby; invite-only, ignored`.
- [ ] A invites B with Ctrl+F1, B accepts: connects normally.

## 5. Robustness
- [ ] A invites B while B is already connected to A: nothing happens (`already in lobby`).
- [ ] B accepts an invite from a third friend C while connected to A: B leaves A and joins C cleanly.
- [ ] Steam overlay disabled on A: Ctrl+F1 shows "the Steam overlay is not available" on the panel.
- [ ] Different builds (B on an older zip): red "Different mod versions" warning, no crash.

## 6. Upstream features to re-verify on the way (README "Current status")
- [ ] Position bug fix (270e2cc): both see each other's position continuously.
- [ ] Shared enemy zone near A; B's hits land on A's enemies; boss safety (A lands the killing blow).
- [ ] Guest loot (`guest_loot=1`): B gets a drop from an enemy B helped kill.
