# M0 Recon: single-PC checklist (Phase B, only after "GO: game testing is clear")

Rewritten 2026-10-31 for the cd-coop-3446 base (D10). Everything offline is already green:
`verify-port.ps1` against the installed exe (1.0.0.3446, PE 0x6AE46DD0), unit tests, room codec, two-instance
loopback. M0 answers what only the running game can: does the mod load, are the live addresses right, does the
game stay stable.

Paths: game `D:\SteamLibrary\steamapps\common\Crimson Desert\bin64`, saves `%LOCALAPPDATA%\Pearl Abyss\CD\save`.
Upstream scripts are in `upstream\cd-coop-3446\scripts\`. Never save the game during these tests.

## 1. Install (game closed)
- [ ] Build the package: `.\tools\package-coopplus.ps1` (must be on a committed HEAD).
- [ ] Unzip `dist\CrimsonDesert-SeamlessCoop-<ver>.zip` to a temp folder and run `Install Co-op+.cmd`.
      Expect: game folder found, save backup in Documents, three files in bin64, `coopplus-installed.txt`.
- [ ] Note the title-screen game version (expected 2.04.00 + hotfix) next to the exe version in the log.

## 2. Load (launch through Steam)
- [ ] `bin64\cdmp.log` starts with `=== Crimson Desert Multiplayer ...` and the build id of the package.
- [ ] Log: version guard accepts the build (PE timestamp 0x6AE46DD0); no "unknown build" refusal.
- [ ] Log: `Co-op+: playing as '<Steam name>' (Steam name)`, `Steam: flat API resolved`, `Steam: ready as ...`,
      `relay network status 100`, `Join: listening for Steam 'Join Game' and invites`.
- [ ] Log: overlay installed (`Overlay: installed true`), sniffer hooks installed.
- [ ] F8 shows the panel. After loading a save: `Room code: XXXXXXX (tell your friend)`, hint `Ctrl+F1: invite`.
- [ ] Anti-cheat / integrity: any warning, refusal or crash at start is written down exactly. If a protection layer
      blocks the mod: stop, report what it is, do not bypass (brief section 8).

## 3. Live addresses (game at the title screen or in the world)
- [ ] `scripts\port-3424-probe.ps1` (read-only, PROCESS_VM_READ) writes `docs\PORT-3424-probe.txt`;
      every .bss global resolves (WorldSystem, Camera, StaticPos, ChunkOrigin, minimap roots).
- [ ] In the world: `Local: pos (...)` in the log changes while walking (the 270e2cc position fix holds).

## 4. One-PC echo (the whole game-side path without a second player)
- [ ] `scripts\testar-um-pc.ps1 -GameBin "<bin64>" -Prepare`, then start the game, load a save, then `-Run`.
      Expect: a copy of yourself follows you with a delay (walk, jump, glide, climb, attack, ride, change gear).
- [ ] Enemy zone dry run lines in the log (nothing hidden in dry run).
- [ ] `-Restore` afterwards (puts cdmp.ini back to Steam).

## 5. Steam UI (one PC; the join itself needs M1)
- [ ] Ctrl+F1 opens the Steam overlay invite dialog for the room (log: `Join: opened the Steam invite dialog`).
- [ ] A friend's Steam client shows you as "Co-op+: hosting (1/2)" with "Join Game" (ask a friend to glance, or
      check from a second Steam account).

## 6. Captures for later milestones (optional, same session)
With `[sniffer] record=1` (50-100 MB per session; turn it off afterwards), do each once and note the time:
learn knowledge from an NPC and a document, discover a region, complete a short side quest, liberate a small camp,
save manually once. These give the payload layouts docs/progression-sync.md needs (M5) and confirm the save opcodes
the save guard watches. With the panel open, hit a few enemies with `[scaling] enabled=1` alone: nothing changes
alone (party of 1) -- the scaling only works with a guest, which is M3.

## 7. Clean exit and removal
- [ ] Quit to desktop without saving: log ends with `Network stopped (mod stopping)` and `Worker exiting`, no crash.
- [ ] `Uninstall Co-op+.cmd`: bin64 back to how it was; the game starts normally.

Record results (pass/fail, log excerpts, exe version) in NOTES/LOG.md and a short line in NOTES/STATE.md, then
commit.
