# M0 Recon: test checklist (Phase B, after "GO: game testing is clear")

Setup (game PC; game is on the D: drive, probably `D:\SteamLibrary\steamapps\common\Crimson Desert\bin64`):
- [ ] Back up `%LOCALAPPDATA%\Pearl Abyss\CD\save` to a dated folder.
- [ ] Note the game version (title screen) and `bin64\CrimsonDesert.exe` file version.
- [ ] Install Ultimate ASI Loader x64 as `bin64\winmm.dll` (or reuse the one another ASI mod already installed).
- [ ] Copy `CrimsonDesertCoop.asi` and the `cdcoop\config\` folder into `bin64\`.
- [ ] Launch normally through Steam.

Checks:
- [ ] `bin64\cdcoop\logs\cdcoop.log` exists and shows the version line and "Game: CrimsonDesert.exe version ...".
- [ ] No log from `crashpad_handler.exe` beyond "not the game process" (or none at all).
- [ ] Steam line: signed in as <name>, lobbies API ok, messages API ok.
- [ ] Probe lines appear every 2 s once signatures for the current build are filled in `probe.toml`:
      player position changes when walking, health drops when hit, world time advances.
- [ ] Vanilla mode: create `bin64\cdcoop\VANILLA`, relaunch: log says co-op disabled, game normal.
- [ ] Remove all mod files: game starts normally (uninstall is clean).
- [ ] Anti-cheat/integrity: note any warning, crash, or refusal to start (if a protection layer blocks the mod: stop,
      write down exactly what it is, and do not bypass it).
