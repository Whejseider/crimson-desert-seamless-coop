# M2 Avatars and M3 Combat/scaling: two-PC checklist (after M1 passes)

Same setup as docs/tests/M1.md (two PCs, same package zip, saves backed up, nobody saves during the session).
A = host, B = guest. Press Ctrl+F12 on both PCs at the same moment before each block, so the logs line up.

## M2: presence
- [ ] Nameplate over B on A's screen shows B's **Steam name**, a health bar and the distance; and the same on B's.
- [ ] Walk apart: the nameplate fades between 25 m and 200 m and disappears beyond 600 m (map pin remains).
- [ ] Ctrl+F8 hides / shows the nameplate; F8 hides / shows only the panel.
- [ ] Minimap arrow and world-map pin for the other player (upstream feature; `[coop] map_pin=1`).
- [ ] Animations: run, jump, glide, climb, ledge pull-up, swim, attack, ride. Note any that freeze or snap.
- [ ] Gear change on B shows on A within a second or two.
- [ ] Known upstream limits to confirm or rule out: copy reloads 1-2 s after dismounting; small jumps of the host's
      copy; sinking/floating with a sideways offset.

## M3: shared enemies and scaling
First without scaling (`[scaling] enabled=0`, the package default):
- [ ] Near A (< 150 m) B sees copies of A's enemies (red minimap dots), B's own enemies hidden (zone on).
- [ ] B's hits lower the real enemy's HP on A; A sees B's blows land.
- [ ] Boss: B helps, A lands the final blow; no cinematic breaks.

Then with scaling (`[scaling] enabled=1` on A only; it is host-side):
- [ ] A's log: `Scaling: 2 player(s), host -> enemies take 1/1.50 ...` when B connects.
- [ ] A hits a regular enemy: HP bar drops, then recovers part of it a moment later; log
      `Scaling: gave enemy 0x... back N HP` (about 1/3 of the blow at x1.5).
- [ ] B hits the same enemy: the blow lands already reduced; log counter `guest blows skipped` increases (they are
      not given back twice).
- [ ] Kill an enemy: it dies normally (no revive), XP and loot as usual for A.
- [ ] Boss (x1.7): same, and no stagger or phase oddities; A still lands the final blow.
- [ ] B disconnects: log `1 player(s)`, A's blows stop being given back.
- [ ] If anything looks wrong (enemy healed fully, never dies, Nak errors in the log): set `enabled=0` again and
      note what happened; the feature stays off by default.

Record results in NOTES/LOG.md, update NOTES/STATE.md, commit.
